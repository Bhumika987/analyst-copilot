Analyst Copilot

What each answer is worth

The grader pays +1 for a correct answer cited to the right place, 0 for an honest “not found,” and −1 for a confident wrong figure. A system that guesses finishes below zero; one that always abstains finishes at exactly zero. Analyst Copilot is built to earn the +1 it can prove and to take a deliberate 0 everywhere else — it is engineered so the −1 row never fires.

How we prevent −1 scores:

  • Only cite verifiable sources: every number is lifted from SEC filing text
  • Never hallucinate: if confidence < 85%, return “not found”
  • Always show location: page + section + exact quote
  • Separate answer from confidence: correctness and location must both score high
  • Reject ambiguous questions: ask for clarification instead of guessing
